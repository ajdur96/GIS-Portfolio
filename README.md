# Avery Durham GIS Portfolio

A portfolio of my GIS work, including graduate projects from the Master's of Science in Geographical Information Science (MSGIS) program at the University of Utah and projects from my GIS internships.

**Live site:** https://ajdur96.github.io/GIS-Portfolio/

## What's inside

- **MSGIS Projects:** Advanced Geographic Data Analysis, Remote Sensing Analysis, Geospatial Big Data, Spatial Modeling & Geocomputation, Data Visualization, Capstone in GIS, and Land Use & Transportation Planning
- **Internships:** Utah State Department of Health, Utah County Elections Division, and Utah County GIS
- **Resume:** Education, work experience, and references

## Skills and tools

Python, R, SQL, ArcGIS Pro, ArcGIS Online, ENVI, NetLogo, Agisoft Metashape, PostgreSQL, SAS, STATA, Java, and HTML

## Repository layout

| Path | Contents |
| --- | --- |
| `index.html` | The full site in one page |
| `images/` | Maps, figures, and photos used on the site |
| `tools/` | The build script and template used to generate `index.html` |

The site was originally built in ArcGIS Experience Builder and moved here so that it no longer depends on an ArcGIS Online account.
